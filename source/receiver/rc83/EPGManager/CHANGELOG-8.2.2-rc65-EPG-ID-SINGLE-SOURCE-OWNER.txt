EPGManager 8.2.2-rc65 - EPG ID single-source owner

- EPG SOURCE ID MONITOR now follows the global SRP master one-owner decision.
- A receiver ServiceRef can be shown MAPPED by one source/channel ID only.

- Existing SRP master priority/manual ownership remains authoritative.
